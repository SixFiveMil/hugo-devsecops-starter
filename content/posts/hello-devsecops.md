Welcome to the **DevSecOps Hugo Starter**. 

This static site is engineered with enterprise-grade quality gates:
- Automated Gitleaks secret scanning before any build artifacts are produced.
- Headless Python HTML security unit tests verifying that unpublished drafts, future-dated articles, and local filesystem paths are never leaked.
- Pre-configured defense-in-depth HTTP security headers (HSTS preload, nosniff, frame-ancestors).
- Zero provider lock-in: deployable to Cloudflare Pages, GitHub Pages, AWS S3, or Netlify.
